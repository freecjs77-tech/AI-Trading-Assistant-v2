이 페이지는 무엇인가요?
Momentum scanner 가 추세 후보로 발견한 종목들 (보유 여부 무관) 의 setup / trigger / decision 을 매일 추적하여, 지금 진입할 만한가 / 아직 기다려야 하는가 / 피해야 하는가 를 판단해 주는 페이지입니다. 자동 매매가 아닌 매수 판단 보조 도구입니다.
보유 종목의 매도 판단(trailing stop)은 Portfolio Risk 페이지를 별도로 참조하세요.
🟢 본 진입 (ENTER)진입해도 OK — 좋은 zone(PULLBACK/BASE)에서 거래량·종가 게이트까지 통과한 확정 trigger. 풀 포지션 가능.
🟡 분할 진입 (PROBE)조기 진입 — 진입 zone 안에서 약한 trigger 발화. 50% 부분 진입 가능, 확정 대기.
🔵 진입 대기 (WATCH)좋은 setup, 트리거 미발생 — PULLBACK/BASE_FORMING zone이나 아직 진입 신호 없음. 반등 신호 관찰.
⚪ 눌림 대기 (TRENDING)추세 진행 중 — TREND_OK지만 setup 압축 부족. 다음 PULLBACK까지 추격 자제.
🔴 매수 금지 (AVOID)회피 — 과확장(EXTENDED)·구조 깨짐(BROKEN)·실패한 trigger(FAILED_BREAKOUT). 진입 시 손실 위험 큼.
상태 용어집 — Setup × Trigger 가 어떻게 Decision 으로 연결되는가

Decision (위 5가지) 은 두 가지 raw 상태의 조합 결과입니다: Setup 은 종목의 추세 구조를 5단계로 진단하고, Trigger 는 그 안에서 진입 신호의 발화 강도를 3단계로 표시합니다.

Setup (구조 진단) — 5단계

평가 우선순위: BROKEN > EXTENDED > BASE_FORMING > PULLBACK > TREND_OK. 한 종목이 여러 조건을 동시에 만족하면 위에 있는 것이 우선 — 추세가 깨졌다면 다른 조건과 무관하게 BROKEN 으로 분류됩니다.

TREND_OK정상 상승 추세 — EMA9 > EMA21 > EMA65 정렬 + EMA65 5일 기울기 양수.
PULLBACK추세 안의 단기 하락 — TREND_OK 조건 + EMA9 와의 거리 ≤ 3% + EMA21 위. 진입 zone.
BASE_FORMING5–15일 횡보 + 변동성 수축 (5d ATR < 20d ATR) + 거래량 수축 (5d 평균 < 20d × 0.85) + EMA21 5일 기울기 양수. VCP 식 압축 베이스 — 가장 시의성 높은 zone.
EXTENDED과확장 — 정렬 유지 + EMA9 와의 거리 > 12% + RSI > 72. 진입 시 손익비 나쁨, 하락 위험 큼.
BROKEN구조 깨짐 — EMA21 < EMA65 (중기 추세 이탈) 또는 종가 < EMA65 (장기 필터 이탈). 추세 자체가 무너진 상태.

Trigger (진입 신호) — 3단계

Setup 이 PULLBACK 또는 BASE_FORMING 일 때만 의미 있음 (그 외에는 항상 WAIT).

WAIT진입 신호 없음.
EARLY_TRIGGEREMA9 reclaim (전일 종가 ≤ EMA9, 오늘 종가 > EMA9) 또는 전일 고점 돌파 + 종가가 일중 상위 20%.
CONFIRMED_TRIGGEREARLY 조건 + 거래량 1.2× (vs 20일 평균) + 종가가 일중 상위 20% (high·low 기준 가중평균).

risk_tags (보조 경고)

중복 부착 가능. 단순 정보용 (FAILED_BREAKOUT 만 Decision 을 강제 AVOID).

OVERHEATRSI ≥ 80.
PARABOLIC1일 수익률 ≥ +8% 동시에 거래량 ≥ 2.0× 평균.
EXTENDEDsetup EXTENDED 와 동일 조건 (mirror).
FAILED_BREAKOUT어제 CONFIRMED → 오늘 종가 < EMA9. 가짜 돌파 — 강제로 AVOID 처리.
