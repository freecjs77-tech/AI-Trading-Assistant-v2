이 페이지는 무엋인가요?

Momentum scanner 가 추세 후보로 발견한 종목들 (보유 여부 무관) 의 setup / trigger / decision 을 매일 추적하여, 지금 진입할 만한가 / 아직 기다려야 하는가 / 피야 하는가 를 판단해 주는 페이지입니다. 자동 매매가 아니 매수 판단 보조 도구입니다.

보유 종목의 매도 판단(trailing stop)은 Portfolio Risk 페이지를 별도로 참조하세요.

🌺 본 진입 (ENTER)진입해도 OK — 준은 zone(PULLBACK/BASE)에서 거래량·종가 게이트곜지 통과한 확정 trigger. 퓐 포지쀵 가능.
🏁 분할 진입 (PROBE)조기 진입 — 진입 zone 안에서 약한 trigger 발화. 50% 부분 진입 가능, 확정 대기.
🔵 진입 대기 (WATCH)주은 setup, 트리거 미발생 — PULLBACK/BASE_FORMING zone이나 아직 진입 신호 없음. 반등 신호 관4û.
⚪ 낥립 대기 (TRENDING)추세 진행 중 — TREND_OK지만 setup 앻젓 부쪟. 다음 PULLBACK곜지 추격 자제.
🔴 매수 금지 (AVOID)회피 — 과확장(EXTENDED)·구조 깆즘(BROKEN)·실퐸한 trigger(FAILED_BREAKOUT). 진입 시 손실 위6èm; 쿐.
help_outline 상태 용어집 — Setup × Trigger 가 어떠게 Decision 으로 연결되는가

Decision (위 5가지) 은 두 가지 raw 상태의 조합 결과입니다: Setup 은 종목의 추세 구조를 5단계로 진단하고, Trigger 는 그 안에서 진입 신호의 발화 강도를 3단계로 표시합니다.

Setup (구조 진단) — 5단계

평가 우선순위: BROKEN > EXTENDED > BASE_FORMING > PULLBACK > TREND_OK

TREND_OK정상 상승 추세 — EMA9 > EMA21 > EMA65 정련 + EMA65 5일 기울기 양수.
PULLBACK추세 안의 단기 하락 — TREND_OK 조건 + EMA9 거리 ≤ 3% + EMA21 위. 진입 zone.
BASE_FORMING5–15일 펓보 + 변동성 수존 (5d ATR < 20d ATR) + 거래량 수존 + EMA21 5일 기울기 양수. VCP 식 앻젓 번이스.
EXTENDED과확장 — 정련 유지 + EMA9 거리 > 12% + RSI > 72.
BROKEN구조 겶즘 — EMA21 < EMA65 똒는 종가 < EMA65.

Trigger (진입 신호) — 3단계

Setup 이 PULLBACK 또는 BASE_FORMING 일 때만 의미 있음.

WAIT진입 신호 없음.
EARLY_TRIGGEREMA9 reclaim 똒는 전일 고점 돌파 + 종가가 일중 상위 20%.
CONFIRMED_TRIGGEREARLY 조건 + 거래량 1.2× + 종가 일중 상위 20%.

risk_tags (보조 경고)

OVERHEATRSI ≥ 80.
PARABOLIC1일 수쨿르 ≥ +8% & 거래량 ≥ 2.0×.
FAILED_BREAKOUT어제 CONFIRMED → 오늘 종가 < EMA9. 곤진 돌파 — 강제로 AVOID.
