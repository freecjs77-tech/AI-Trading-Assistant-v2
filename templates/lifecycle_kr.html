상태 용어집 — Setup × Trigger 가 어떻게 Decision 으로 연결되는가

Decision (위 4가지) 은 두 가지 raw 상태의 조합 결과입니다: Setup 은 종목의 추세 구조를 5단계로 진단하고, Trigger 는 그 안에서 진입 신호의 발화 강도를 3단계로 표시합니다.

Setup (구조 진단) — 5단계

평가 우선순위: BROKEN > EXTENDED > BASE_FORMING > PULLBACK > TREND_OK. 한 종목이 여러 조건을 동시에 만족하면 위에 있는 것이 우선 — 추세가 깨졌다면 다른 조건과 무관하게 BROKEN 으로 분류됩니다.

TREND_OK정상 상승 추세 — EMA9 > EMA21 > EMA65 정렬 + EMA65 5일 기울기 양수.
PULLBACK추세 안의 단기 하락 — TREND_OK 조건 + EMA9 와의 거리 ≤ 3% + EMA21 위. 진입 zone.
BASE_FORMING5–15일 횡보 + 변동성 수축 (5d ATR < 20d ATR) + 거래량 수축 (5d 평균 < 20d × 0.85) + EMA21 5일 기울기 양수. VCP 식 압축 베이스 — 가장 시의성 높은 zone.
EXTENDED과확장 — 정렬 유지 + EMA9 와의 거리 > 12% + RSI > 72. 진입 시 손익비 나쁨, 하락 위험 큼.
BROKEN구조 깨짐 — EMA21 < EMA65 (중기 추세 이탈) 또는 종가 < EMA65 (장기 필터 이탈). 추세 자체가 무너진 상태.

Trigger (진입 신호) — 3단계

Setup 이 PULLBACK 또는 BASE_FORMING 일 때만 의미 있음 (그 외에는 항상 WAIT).

WAIT진입 신호 없음.
EARLY_TRIGGEREMA9 reclaim (전일 종가 ≤ EMA9, 오늘 종가 > EMA9) 또는 전일 고점 돌파 + 종가가 일중 상위 20%.
CONFIRMED_TRIGGEREARLY 조건 + 거래량 1.2× (vs 20일 평균) + 종가가 일중 상위 20% (high·low 기준 가중평균).

risk_tags (보조 경고)

중복 부착 가능. 단순 정보용 (FAILED_BREAKOUT 만 Decision 을 강제 AVOID).

FAILED_BREAKOUT어제 CONFIRMED → 오늘 종가 < EMA9. 가짜 돌파 — 강제로 AVOID 처리.
