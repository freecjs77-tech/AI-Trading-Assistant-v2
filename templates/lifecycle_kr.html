이 페이지는 무엇인가요?

Momentum scanner 가 추세 후보로 발견한 종목들 (보유 여부 무관) 의 setup / trigger / decision 을 매일 추적하여, 지금 진입할 만한가 / 아직 기다려야 하는가 / 피야 하는가 를 판단해 주는 페이지입니다. 자동 매매가 아니 매수 판단 보조 도구입니다.

보유 종목의 매도 판단(trailing stop)은 Portfolio Risk 페이지를 별도로 참조하세요.

help_outline 상태 용어집 — Setup × Trigger 가 어떻게 Decision 으로 연결되는가

Decision (위 5가지) 은 두 가지 raw 상태의 조합 결과입니다: Setup 은 종목의 추세 구조를 5단계로 진단하고, Trigger 는 그 안에서 진입 신호의 발화 강도를 3단계로 표시합니다.

Setup (구조 진단) — 5단계

평가 우선순위: BROKEN > EXTENDED > BASE_FORMING > PULLBACK > TREND_OK

TREND_OK정상 상승 추세 — EMA9 > EMA21 > EMA65 정렬 + EMA65 5일 기울기 양수.
PULLBACK추세 안의 단기 하락 — TREND_OK 조건 + EMA9 거리 ≤ 3% + EMA21 위. 진입 zone.
BASE_FORMING5–15일 횡보 + 변동성 수축 (5d ATR < 20d ATR) + 거래량 수축 + EMA21 5일 기울기 양수. VCP 식 압축 베이스.
EXTENDED과확장 — 정렬 유지 + EMA9 거리 > 12% + RSI > 72.
BROKEN구조 깨짐 — EMA21 < EMA65 또는 종가 < EMA65.

Trigger (진입 신호) — 3단계

Setup 이 PULLBACK 또는 BASE_FORMING 일 때만 의미 있음.

WAIT진입 신호 없음.
EARLY_TRIGGEREMA9 reclaim 또는 전일 고점 돌파 + 종가가 일중 상위 20%.
CONFIRMED_TRIGGEREARLY 조건 + 거래량 1.2× + 종가 일중 상위 20%.

risk_tags (보조 경고)

OVERHEATRSI ≥ 80.
PARABOLIC1일 수쨿르 ≥ +8% & 거래량 ≥ 2.0×.
FAILED_BREAKOUT어제 CONFIRMED → 오늘 종가 < EMA9. 가짜 돌파 — 강제로 AVOID.
