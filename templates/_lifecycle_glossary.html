시스템은 종목을 두 축으로 보고 최종 그룹을 정합니다:
① Setup (구조 진단) × ② Trigger (진입 신호)
Setup \ Trigger WAIT
(신호 없음)		 EARLY
(약한 신호)		 CONFIRMED
(거래량 동반)
TREND_OK (추세) ⚪ 눌림 대기 (TRENDING)
PULLBACK (눌림) 🔵 WATCH 🟡 PROBE 🟢 ENTER
BASE_FORMING (베이스) 🔵 WATCH 🟡 PROBE 🟢 ENTER

Setup (구조 진단) — 5단계
종목의 추세 구조를 진단하는 5단계 분류. 평가 우선순위: BROKEN > EXTENDED > BASE_FORMING > PULLBACK > TREND_OK
단계의미판정 조건
TREND_OK 정상 상승 추세 EMA9 > EMA21 > EMA65 정렬 + EMA65 5일 기울기 양수
PULLBACK 추세 안의 단기 하락 (=진입 자리) TREND_OK 조건 + EMA9 거리 ≤ {{ (lifecycle_thresholds.PULLBACK_MAX_DIST_FROM_EMA9 * 100)|round(0)|int }}% + EMA21 위
BASE_FORMING {{ lifecycle_thresholds.BASE_FORMING_DAYS_MIN }}–{{ lifecycle_thresholds.BASE_FORMING_DAYS_MAX }}일 횡보 + 변동성 수축 (=VCP) 5d ATR < 20d ATR + 거래량 수축 + EMA21 기울기 양수
EXTENDED 과확장 정렬 유지 + EMA9 거리 > {{ (lifecycle_thresholds.EXTENDED_DIST_FROM_EMA9 * 100)|round(0)|int }}% + RSI > {{ lifecycle_thresholds.EXTENDED_RSI_MIN }}
BROKEN 구조 깨짐 EMA21 < EMA65 또는 종가 < EMA65
Trigger (진입 신호) — 3단계
Setup이 PULLBACK 또는 BASE_FORMING일 때만 의미 있음.
